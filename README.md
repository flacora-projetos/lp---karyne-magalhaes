# Run and deploy your AI Studio app

This contains everything you need to run your app locally.

View your app in AI Studio: https://ai.studio/apps/62752740-d129-456d-824c-b67c2a0c14a4

## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Set the `GEMINI_API_KEY` in [.env.local](.env.local) to your Gemini API key
3. Run the app:
   `npm run dev`

## Revisão de acessibilidade do filtro

No navegador, abra o menu móvel e o filtro pelo teclado. Confira foco ao avançar, voltar e fechar, preenchimento automático dos campos e validação nativa do nome e e-mail. Use dados e respostas simulados para o CRM, o WhatsApp e as tags. Rode `npm run lint`, `npm run test:blog` e `npm run build`.
